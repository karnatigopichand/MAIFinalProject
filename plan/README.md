# Project planning documents

This folder contains the original design baseline and implementation notes for the e-commerce repository impact assessment demo. It is not the source of truth for current runtime behavior; see the root [README](../README.md) for setup and runnable commands. The architecture and implementation plans below distinguish completed local features from optional integrations and account/deployment work that still needs configuration.

Read in this order:

1. [Overall project plan](overall-plan.md): scope, repositories, architecture, data pipeline, ownership, milestones, and evaluation.
2. [Impact Investigation Agent](impact-investigation-agent.md): ticket understanding and evidence-backed dependency investigation.
3. [Technical Debt Agent](technical-debt-agent.md): related improvements and opportunities to share testing.
4. [Risk and Report Agent](risk-report-agent.md): verification, business risk, and final response.
5. [Shared contracts and integration](shared-contracts.md): interfaces that allow independent development.
6. [E-commerce implementation plan](ecommerce-implementation-plan.md): Codex work sequence, implemented sample services, tests, documentation, and remaining integration work.
7. [Agent architecture and local implementation](agent-architecture-and-mvp.md): current workflow, retrieval tools, hosted stores, Jira, observability, evaluation, and remaining integration gaps.

Target completion: November 6–7, 2026. Demo: November 10, 2026.

Planning assumptions requiring team confirmation are explicitly identified in the overall plan. These documents do not configure external accounts or claim that Jira, hosted stores, broker, or Replit deployment is live.
